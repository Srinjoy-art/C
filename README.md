# C Programming

Hey! I'm a first-year B.Tech CSE student at JIS Kalyani, currently learning C and trying to get better at solving problems through code.
This repository is where I'm keeping the programs I've written while learning the basics. I'm starting small, understanding how things work, and gradually moving towards more challenging problems.

### What's inside?

- **Decimal to Binary** — converting decimal numbers into binary.
- **Fibonacci Series** — generating Fibonacci numbers.
- **Number of Digits** — counting the digits in a number.
- **Palindrome Number** — checking whether a number reads the same forwards and backwards.
- **Prime or Not** — checking if a number is prime.
- **Sum of Digits** — finding the sum of a number's digits.

### What I'm learning

- C fundamentals and syntax
- Loops and conditional statements
- Functions and problem-solving
- Writing code that's easier to understand and maintain

I wanted a place to keep track of what I've learned instead of letting my practice programs sit forgotten on my computer. I'll keep adding new programs as I learn more.
